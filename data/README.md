Place the supplied source CSVs here or in another local directory:

- customer_churn_dataset-training-master.csv
- customer_churn_dataset-testing-master.csv

Source: Muhammad Shahid Azeem, Customer Churn Dataset, Kaggle version 1.
https://www.kaggle.com/datasets/muhammadshahidazeem/customer-churn-dataset

The original bytes are intentionally excluded from Git and from the project ZIP.
The run manifest records their SHA-256 fingerprints and sizes. The data card does
not establish observation timestamps, a predictive horizon, spending currency or
the real-world sampling process. Synthetic smoke-test files are generated separately.
